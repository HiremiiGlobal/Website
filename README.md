# AQYR Global Services

Next.js App Router project that brings the existing bilingual AQYR website demo into a Next.js application while preserving its current pages, styles, language switch, and interactions.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Build for deployment

```bash
pnpm build
pnpm start
```

## Editing and previews

- Edit page text and bilingual copy in `content/*.html`.
- Edit shared styles in `style.css` and interactions in `public/script.js`.
- Use the local Next.js server for the main preview. The root HTML files are static preview copies, not the deployed content source.
- After an edit, run `pnpm sync:preview` to refresh those static copies.
- The Chinese/English button keeps the same URL and remembers the visitor's preference; a new visitor starts in English.
- The enquiry form only prepares a mailto draft. The visitor must send it from their email app.

Page content is rendered on the server rather than appended after loading. Old `.html` URLs redirect to the corresponding page, preserving existing links.

## Search metadata

Page titles, descriptions and canonical URLs are defined in `lib/site.ts`; the sitemap and robots file are generated by Next.js.
When connecting a final domain, set `NEXT_PUBLIC_SITE_URL` to its HTTPS origin in Vercel and redeploy. Do not use a preview-deployment URL for this setting.

The shared link preview uses `public/share-cover.png`, the original AQYR logo and the name AQYR Global Services. Open Graph and Twitter image settings are in `lib/site.ts`.

## Local media

Original portraits stay in `public/team/*.jpg`. The website uses responsive 240px and 480px WebP copies. Run `pnpm prepare:media` after replacing an original portrait or the logo to regenerate those copies and the share cover, then run `pnpm sync:preview`.

Editorial scene photos are stored locally in `public/scenes`, with responsive 640px, 960px and 1440px WebP copies generated by the same command. Their source pages, photographers and licenses are recorded in `assets/photography.json`. The active scenes show Melbourne architecture, an individual city-life perspective and a workplace; previous conversation assets are retained but are not displayed. These are illustrative photographs, not AQYR staff, clients, offices or case results. The homepage photo caption describes the team's case-by-case approach, not a software product or automated visa assessment. Site visitors do not depend on the stock-photo hosts for image loading.
